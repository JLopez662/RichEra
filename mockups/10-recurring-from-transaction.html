Mark a transaction as recurring

Adds a Repeat toggle to the detail modal. Flip it on, pick a period, and it spins up a recurring rule pre-filled from this transaction — reusing the engine behind Income Sources (which already does expenses too). The transaction itself becomes the rule's first occurrence, so nothing double-counts.
