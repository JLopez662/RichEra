Rich Era — UI mockups

Standalone HTML sketches, one design question each. Built mobile-first since you'll use this on a phone. Newer ones (11+) use the real Aurora/Midnight theme tokens to match the app.

01

Setup form + projection

Define a recurring rule once. See the next 6 paychecks generated live. Each becomes a real, editable transaction.
02

Paycheck ledger

Monthly groups. Received paychecks vs projected, with one-tap edit to override an amount when it differs from the rule.
03

Calendar view

Visual month grid with paychecks pinned to their Friday. Projected ones look faded. Tap to edit.
04

Forecast dashboard

Power-user view. Projected vs actual per month, variance, plus auto-flagging of "three-paycheck months."
05

Home dashboard redesign

Balance hero up top, compact income/expense/net with a flow bar, next-paycheck card, cleaner accounts, and a quick-action bar.
06

Transactions / expense UI

Month stepper, spent/income/net chips, day-grouped list with category icons, and a mobile add-expense sheet with an amount field and category chips.
07

Set current balance

Directly correct an account's stored balance. Hero "new balance" field, a current→adjustment readout, and an optional toggle to log the difference as a transaction.
08

Accounts screen redesign

The Bootstrap table doesn't fit a phone. Two mobile-first replacements: a compact list with a ⋯ action sheet, and expanded cards with always-visible buttons. Plus a net-worth header.
09

Transaction detail modal

Tapping a row opens a read-only detail modal in place over the list before editing — full untruncated description, bank reference (FITID), and source. Adapts for imported, manual, and transfer rows.
10

Mark a transaction recurring

A Repeat toggle in the detail modal: flip it on, pick a period (weekly / every 2 weeks / monthly), and it creates a recurring rule pre-filled from the transaction. Shows off, picking, and already-recurring states.
11

Quick balance update from Home

An edit button on the balance hero (two placements) opening a live quick-reconcile sheet: type each account's real balance, the new total follows, adjustments reuse the existing reconcile machinery. Aurora/Midnight themed.
12

Money Log — Lose It! for money

Full concept gallery: budget ring + money groups (the Log), the Money Facts label with debt/growth micros and %-of-budget, the item Library absorbing Shop + Income sources, editor with autofill, Home integration, and the page-restructure map with build phases.
